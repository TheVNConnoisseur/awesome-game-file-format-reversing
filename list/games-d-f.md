- [TAE Importer/Exporter for Elden Ring](https://github.com/FWang1221/TAE-Importer-Exporter-For-Elden-Ring) - Tool for importing/exporting TAE (Time Act Editor) animation files for Elden Ring.
- [FBX2FLVER-MTDFIX](https://github.com/infernoplus/FBX2FLVER-MTDFIX) - Tool to import FBX models into Dark Souls 1 flver format with MTD fixing.
- [FLVER_Editor](https://github.com/asasasasasbc/FLVER_Editor) - Multifunctional editor to edit and view FromSoftware game's FLVER files (Sekiro, Dark Souls, Bloodborne, etc.).
- [blender-flver](https://github.com/elizagamedev/blender-flver) - Blender addon for importing/exporting FLVER models from FromSoftware games. Supports Dark Souls, Dark Souls: Remastered, Bloodborne, and Sekiro.
- [FromSoftware-Blender-Importer](https://github.com/FelixBenter/FromSoftware-Blender-Importer) - Blender importer for FromSoftware FLVER formats. Supports Dark Souls 1, 2, 3, and Sekiro: Shadows Die Twice (characters, partsbnds, and maps for DS1/DS3).
- [soulstruct-blender](https://github.com/Grimrukh/soulstruct-blender) - Blender plugin for soulstruct.
- [DSAnimStudio](https://github.com/Meowmaritus/DSAnimStudio) - Animation and cutscene editor for Souls games.
- [dark_souls_hkx](https://github.com/Danilodum/dark_souls_hkx) - Noesis plugins for Dark Souls HKX (Havok animation) format with extra root bone and root motion support.
- [soulstruct-havok](https://github.com/Grimrukh/soulstruct-havok) - Havok HKX file reader and writer for Dark Souls game animations and physics.
- [ERClipGeneratorTool](https://github.com/The12thAvenger/ERClipGeneratorTool) - Editor for hkbClipGenerators in Havok Behavior (.hkx) animation files.
- [DS3BehaviorTool](https://github.com/The12thAvenger/DS3BehaviorTool) - Tool for editing Dark Souls 3 behavior binders (behbnd): registers animations for TAE sections and edits hkbClipGenerators, hkStateMachineStateInfos, hkManualSelectorGenerators, CustomManualSelectorGenerators and hkVariableBindingSets, with config presets for mass editing.
- [DS3HavokConverter](https://github.com/The12thAvenger/DS3HavokConverter) - Converts Havok 2018 XML packfiles to Havok 2014 for Dark Souls 3, supporting Havok Cloth, Physics and Animation.
- [DS3RagdollConverter](https://github.com/The12thAvenger/DS3RagdollConverter) - Converts Havok 2010 ragdoll XML files to the Havok 2014 format for use with Dark Souls 3, and supports porting Dark Souls 1 ragdolls to Dark Souls 3.
- [SoulsAssetPipeline](https://github.com/Meowmaritus/SoulsAssetPipeline) - C# pipeline for importing and exporting assets from FromSoftware's Souls games, built on top of SoulsFormats.
- [BBAnimConverter](https://github.com/Sanadsk/BBAnimConverter) - Converts Dark Souls 3 and Bloodborne PS4 Havok animations into HavokTools-friendly files.
- [JortPob](https://github.com/infernoplus/JortPob) - Total conversion tool that ports Morrowind's assets (models, terrain, NPCs, dialogue) into Elden Ring via ModEngine3, converting Bethesda's data into FromSoftware's FLVER/BND/MSB formats and Wwise audio pipeline.
- [SoulsGrassConvert](https://github.com/ividyon/SoulsGrassConvert) - Tool for Souls modding (Elden Ring, Sekiro, Armored Core VI) to convert and edit GRASS files as GLTF files.
- [ERMaterialConvertTool](https://github.com/ividyon/ERMaterialConvertTool) - Tool for Elden Ring modding to convert one FLVER (model file) material to another.
- [FbxImporter](https://github.com/The12thAvenger/FbxImporter) - Tool for importing FBX meshes into FLVER model files, supporting vertex-deformed cloth meshes, for Dark Souls 3, Sekiro, and Elden Ring.
- [FlverFixer](https://github.com/GompDS/FlverFixer) - Fixes GX lists and buffer layouts in FLVER model files to match the materials used by the mesh, for Dark Souls 3, Sekiro and Elden Ring.
- [FlverFixup](https://github.com/The12thAvenger/FlverFixup) - Command-line tool for fixing common issues with FLVER model files, processing loose files or BND archives (Oodle DLL from the game directory required for BNDs).
- [MTD-Editor](https://github.com/JKAnderson/MTD-Editor) - Material definition (MTD) editor for FromSoftware games.
- [DSR-TPUP](https://github.com/JKAnderson/DSR-TPUP) - Utility to extract and replace textures in Dark Souls: Remastered.
- [MassConvertFromModel](https://github.com/WarpZephyr/MassConvertFromModel) - Mass converts FLVER0, FLVER2, MDL4 and SMD4 FromSoftware models to formats such as FBX through AssimpNet (known normal and UV issues; SMD4 not fully explored).
  - [FromAssimp](https://github.com/WarpZephyr/FromAssimp) - Imports FLVER0, FLVER2, MDL4 and SMD4 models into Assimp for export to common formats such as FBX, with the same normal and UV caveats.
  - [FlverInfoDump](https://github.com/WarpZephyr/FlverInfoDump) - Dumps basic information (without indices or vertices) from MDL4, SMD4, FLVER0 and FLVER2 models to a text file beside the model.
- [FlverFlow](https://github.com/WarpZephyr/FlverFlow) - Work-in-progress FLVER model importer and exporter with a GUI; its documented workflow targets Armored Core: For Answer models (material.bnd plus model and texture BNDs).
- [Timspect](https://github.com/WarpZephyr/Timspect) - Unpacks and repacks PlayStation TIM2 textures (to PNG plus an XML of texture properties) and includes a TIM texture viewer, focused on FromSoftware TIM2 files.

##### Scripting, FX, Params & Runtime Modding

- [DemonsSoulsDebug](https://github.com/gibbed/DemonsSoulsDebug) - Patches for Demon's Souls to enable debug menus and other developer functionality.
- [Dark-Souls-II-Mod-Loader](https://github.com/Atvaark/Dark-Souls-II-Mod-Loader) - File system hook for modding and runtime file replacement.
- [DarkScript3](https://github.com/AinTunez/DarkScript3) - IDE for editing FromSoftware's EMEVD event script files with a high-level JavaScript-like language (MattScript).
- [ESDStudio](https://github.com/GompDS/ESDStudio) - Desktop app for editing FromSoftware Talk ESD (dialogue/behavior state machine) files.
- [py_esd_for_des](https://github.com/moitt22/py_esd_for_des) - Python decompiler/compiler for Demon's Souls' Talk ESD event script files.
- [EldenRingHKS](https://github.com/soulsmods/EldenRingHKS) - Curated repository of Elden Ring HKS (HavokScript) AI/behavior script edits, useful reference for HavokScript decompilation/modding work.
- [FxrQuery](https://github.com/GompDS/FxrQuery) - Gathers FXR particle-effect data from a Dark Souls 3/Elden Ring install using a game-directory Config.xml and an FXR-ID spreadsheet CSV.
- [CutsceneEdit](https://github.com/GompDS/CutsceneEdit) - Console tool to move and rotate cameras/objects in Dark Souls 3 MQB cutscene files via simple command syntax.
- [nightreign-map-extract](https://github.com/focusmade/nightreign-map-extract) - Self-contained Rust CLI that extracts and stitches world map tiles from Elden Ring: Nightreign game archives.
- [param_field_mapper](https://github.com/tremwil/param_field_mapper) - Reverse engineering utility for Armored Core 6 that uses vectored exception handling to monitor accesses to param memory and generate typed XML paramdefs.
- [ParamStructGenerator](https://github.com/tremwil/ParamStructGenerator) - Generates C/C++ structs from XML paramdefs and a regulation file; the regulation parsing is hardcoded for Elden Ring.

##### Armored Core

- [Cauldron](https://github.com/WarpZephyr/Cauldron) - Modding tool for Armored Core: For Answer, Armored Core V, and Armored Core: Verdict Day, with DAT format support.
- [AcParamEditor](https://github.com/WarpZephyr/AcParamEditor) - Lightweight param editor for Armored Core 4, For Answer, V, Verdict Day and 6, plus Armored Core Formula Front, Chromehounds and Enchanted Arms, driven by per-game paramdef folders (XML or raw paramdefs).
  - [ParamDbpEditor](https://github.com/WarpZephyr/ParamDbpEditor) - Editor for the dbp-based params (and the dbps themselves) used by Armored Core 4, For Answer, V and Verdict Day.
  - [ParamDefEditor](https://github.com/WarpZephyr/ParamDefEditor) - Editor for creating and editing paramdefs and exporting them to XML (importing the XML back is noted as broken).
- [AcMsbEditor](https://github.com/WarpZephyr/AcMsbEditor) - Simple editor for Armored Core 4 MSB map files that can add, delete and duplicate MSB param entries (it cannot yet edit entry properties).
- [FsUnboundMapper](https://github.com/WarpZephyr/FsUnboundMapper) - Unpacks Armored Core game files into a loose setup the game can load, covering For Answer, V and Verdict Day on PS3 and Xbox 360 (Armored Core 4 is listed but not yet marked as supported).
  - [ACVLooseLoader](https://github.com/WarpZephyr/ACVLooseLoader) - Automates loose loading for Armored Core V and Verdict Day on PS3 and Xbox 360: unpacks the main archives, boot, script and mission binders, packs map models and textures into binders for V, and hides the archive header files.
- [REGUExtract](https://github.com/WarpZephyr/REGUExtract) - Unwraps regulation.bin from REGU.DAT in Armored Core Verdict Day save files as regulation.bnd (for Yabber) and repacks it.
  - [RegulationHashCalculator](https://github.com/WarpZephyr/RegulationHashCalculator) - Recalculates the md5 hash entry in Armored Core 4's regulation.bin BND3 after editing.
  - [EncrMake](https://github.com/WarpZephyr/EncrMake) - Unpacks and repacks the ENCR encrypted payloads Armored Core 4 receives for patch and regulation updates at startup.
- [AcSaveConverter](https://github.com/WarpZephyr/AcSaveConverter) - Opens and exports Armored Core saves between platforms and regions; Armored Core: For Answer on PS3 and Xbox 360 is the supported game so far.
  - [AcSaveFormats](https://github.com/WarpZephyr/AcSaveFormats) - Companion C# library for reading and writing Armored Core saves.
- [ac6sl2tool](https://github.com/WarpZephyr/ac6sl2tool) - Decrypts and encrypts the files inside Armored Core 6 SL2 saves and recalculates their trailing checksum (the SL2 itself is a BND4 to unpack first with Yabber or WitchyBND).
- [souls_givifier](https://github.com/jtesta/souls_givifier) - Save game editor for Dark Souls Remastered, Dark Souls II: Scholar of the First Sin, Dark Souls III, and Elden Ring, reading and writing the shared save data format across titles.
- [DarkSoulsII.DebugView](https://github.com/Atvaark/DarkSoulsII.DebugView) - Debug view/inspector for Dark Souls II's in-memory and save data structures.
